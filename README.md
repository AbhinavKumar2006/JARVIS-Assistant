# JARVIS Assistant

A desktop JARVIS-style assistant made using JavaFX and Python.

## Features

- JavaFX GUI
- Python backend
- Ollama Llama model support
- Text chat
- Voice mode
- Text-to-speech
- File upload support
- Chat history saving

## Requirements

- Java JDK 21
- JavaFX SDK
- Python 3
- Ollama
- llama3.2 model
- Tesseract OCR
- Vosk speech model

## Install Python Packages

Open PowerShell in the project folder and run:

pip install -r requirements.txt

## Install Ollama Model

This project uses the llama3.2 model.

Run:

ollama pull llama3.2

To check:

ollama list

To test:

ollama run llama3.2

## Run Project

Run:

JARVIS.bat
